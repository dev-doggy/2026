# 🔑 Консольный генератор паролей

Привет! Это компактная и полезная утилита на C#, которую я написала сама. Программа быстро генерирует случайный надежный пароль из букв и цифр.

## 🎮 Как работает программа?
* **Ввод длины:** При запуске программа запрашивает у пользователя желаемую длину будущего пароля.
* **Случайный подбор:** Утилита берет подготовленный набор символов (буквы и цифры) и с помощью генератора случайных чисел (`Random`) собирает их в строку.
* **Вывод:** Программа выводит на экран готовый пароль, готовый к использованию.

## 🛠 Как устроен код?
Программа написана на **C#** в максимально лаконичном и чистом виде. Весь алгоритм реализован в одном главном методе `Main`. В коде нет ничего лишнего: только ввод данных, цикл сборки строки и вывод результата в консоль. Это делает утилиту быстрой и легкой для понимания.

## 🚀 Как запустить?
1. Скачайте проект к себе на компьютер.
2. Откройте его в Visual Studio или VS Code.
3. Нажмите кнопку запуска (`F5`) и сгенерируйте свой пароль!
